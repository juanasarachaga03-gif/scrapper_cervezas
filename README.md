# scrapper_cervezas

## Descargar los reportes

Los reportes diarios (Cadenas Nacionales, Cadena Interior y Last Millers) se publican todos los días en la sección **Releases** del repo. No hace falta cuenta de GitHub:

https://github.com/juanasarachaga03-gif/scrapper_cervezas/releases

Cada release se llama `Reportes AAAA-MM-DD` y trae los `.xlsx` de ese día; se bajan haciendo click en el nombre del archivo dentro de "Assets".
